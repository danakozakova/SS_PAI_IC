Spomínaš si na minulú hodinu?

Na tabuli sme spoločne vyriešili algoritmus na nájdenie maxima z troch čísel. Zapísali sme ho ako pseudokód — kroky zrozumiteľné pre človeka.

Dnes uvidíš, že pseudokód a Python si sú veľmi podobné. Stačí naučiť sa, ako Python „číta" tie isté kroky.

Od pseudokódu k Pythonu

Tu je algoritmus maxima z troch čísel — presne tak, ako sme ho mali na tabuli — a vedľa neho Python kód, ktorý robí to isté:

Pseudokód (z tabule)
1. načítaj(x)
2. načítaj(y)
3. načítaj(z)
4. ak x ≥ y, tak max←x
5. ak x < y, tak max←y
6. ak max < z, tak max←z
7. vypis(max)
Python
x = int(input("x: "))
y = int(input("y: "))
z = int(input("z: "))
if x >= y:
    max = x
else:
    max = y
if max < z:
    max = z
print(max)
💡 Všimni si: každý krok pseudokódu sa stáva jedným (alebo dvoma) riadkami Pythonu. Logika je úplne rovnaká — mení sa iba zápis.

Skopíruj Python kód do editora, spusti ho a vyskúšaj vstup x=67, y=69, z=1000 — dostaneš rovnaký výsledok ako na tabuli.

Tri veci, ktoré dnes potrebuješ

1. Výstup — print()

print("Ahoj, svet!")      # vypíše text
print(42)               # vypíše číslo
print("Výsledok:", 42)  # vypíše text a číslo

2. Vstup — input()

meno = input("Ako sa voláš? ")
print("Ahoj,", meno)

3. Konverzia na číslo — int() a float()

# input() VŽDY vráti text (reťazec)
# Bez konverzie by "12" + "8" = "128"  (lepenie textu!)
a = int(input("Zadaj číslo: "))    # celé číslo
b = float(input("Zadaj číslo: "))  # desatinné číslo
⚠️ Najčastejšia chyba: zabudnutie int() alebo float() pri vstupe.
Skús sám: napíš program bez konverzie, zadaj dve čísla a pozoruj, čo sa stane.

Debugger — krokovanie v VS Code

Keď program nefunguje tak, ako by mal, pomôže ti debugger — nástroj, ktorý ti dovolí sledovať program krok za krokom a vidieť hodnoty premenných v každom okamihu.

🔍 Čo je breakpoint (bod prerušenia)?
Klikni na ľavý okraj editora (vedľa čísla riadku) — objaví sa červená bodka. Program sa na tomto mieste zastaví a čaká na teba.

Ako spustiť debugger vo VS Code

klik na okraj

Nastav breakpoint
Červená bodka na riadku, kde chceš zastaviť.

F5

Spusti s debuggerom
Program beží, až kým nenarazí na breakpoint.

F10

Step Over — krok
Vykoná jeden riadok a zastaví sa na nasledujúcom.

F11

Step Into — vstúp
Vstúpi do volania funkcie (napr. do tela input()).

Shift+F5

Zastav
Ukončí debugger a beh programu.

Panel Premenné (Variables)

Keď je program zastavený na breakpointe, v ľavom paneli VS Code uvidíš sekciu VARIABLES. Tam nájdeš meno a aktuálnu hodnotu každej premennej — presne tak, ako si v Turbo Pascale videla stav premenných počas krokovania.

Klávesová skratka Čo robí
F5Spusti / Pokračuj (Continue) — beh do ďalšieho breakpointu
F10Krok (Step Over) — vykoná aktuálny riadok, zastaví na nasledujúcom
F11Vstúp (Step Into) — prejde dnu do funkcie na aktuálnom riadku
Shift+F11Vystúp (Step Out) — dokončí funkciu a vráti sa o úroveň vyššie
Shift+F5Zastav debugger
klik na okrajZapni / vypni breakpoint na tomto riadku

🔬 Praktická úloha — krokuj algoritmus maxima

  1. Otvor vo VS Code súbor uloha4.py (maximum z troch čísel).
  2. Nastav breakpoint na prvý riadok (x = int(input(...))).
  3. Stlač F5 a zadaj hodnoty x=67, y=69, z=1000.
  4. Striedaj F10 (krok za krokom) a sleduj panel VARIABLES:
    • Po treťom input(): aké sú hodnoty x, y, z?
    • Po prvom if x >= y: vstúpil program do if alebo else? Prečo?
    • Po druhom if max < z: zmenila sa hodnota max? Na čo?
    • Na konci: čo vypíše print(max)?
  5. Zopakuj s hodnotami x=10, y=5, z=3 — porovnaj, kadiaľ program išiel tentokrát.
💡 Tip: Debugger neklamie — ak si myslíš, že premenná má inú hodnotu, ako ti ukazuje panel, chyba je v tebe, nie v programe. Prečítaj kód znova.

🎯 Mini-projekt — Kalkulačka vlastností čísla

Program načíta jedno celé číslo a vypíše o ňom tieto informácie:

  • ✅ Je číslo kladné, záporné alebo nula?
  • ✅ Je číslo párne alebo nepárne?   (nápoveda: n % 2)
  • ✅ Aká je jeho absolútna hodnota?   (nápoveda: abs(n))
  • ✅ Aký je jeho štvorec?   (nápoveda: n ** 2)

Vzorový výstup pre vstup -6:

Zadaj celé číslo: -6
Číslo -6 je záporné.
Číslo -6 je párne.
Absolútna hodnota: 6
Štvorec: 36

Postup: Najprv si nakresli do zošita, čo program robí (vstup → spracovanie → výstup). Až potom kóduj.
